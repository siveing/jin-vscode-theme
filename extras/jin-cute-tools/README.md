# Jin Cute Tools

A personal companion to Jin Cute Theme. It isn't published. Install it from the repository root with `npm run install-tools`.

| Mac | Windows/Linux | What it does |
| --- | --- | --- |
| Cmd+R | Ctrl+R | **Go to Function**: lists only the functions, methods and constructors in the current file. Type to filter, use ↑/↓ to preview, Enter to jump, Esc to go back. |
| Cmd+I | Ctrl+I | **Go to Implementation** for the symbol under the cursor. |

It also sets these editor defaults: a thin line cursor that glides and pulses, smooth scrolling, indentation shown as faint dots (`renderWhitespace: "boundary"`), and bracket pair guide lines.
