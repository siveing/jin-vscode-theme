# Changelog

## 0.2.1

- Functions and arguments are now clearly different in both themes: functions are blue (soft sky in dark, azure in light), and arguments are italic butter yellow (dark) or magenta (light).
- Properties move to lavender (dark) and cyan (light) so they don't clash with functions or arguments.
- Jin Cute Dark no longer uses amber or orange for code: numbers are coral, strings mint green, decorators lavender, and escapes and namespaces hot pink and teal.
- Dark code colors are evenly bright (about 10:1 contrast), so nothing glares.
- The second bracket pair color is violet in both themes.

## 0.2.0

- Screenshots now use Fira Code with ligatures.
- Recommended settings add Fira Code and horizontal bracket pair guides (`editor.guides.bracketPairsHorizontal`), which draw a pink line from the cursor's block to its opening bracket.
- Jin Cute Light no longer has brown tones: code text avoids orange, amber and yellow, numbers are crimson, strings a cleaner green, and warnings, search matches and terminal yellows use vivid orange and gold.
- Inline code in hovers and docs is pink.

## 0.1.0

First release.

- **Jin Cute Dark**: true black backgrounds with pink accents.
- **Jin Cute Light**: soft blush backgrounds with deeper pinks.
- Full workbench coverage, terminal colors, git decorations, diff and merge views, bracket pair colors and semantic highlighting.
- All code colors meet a 4.5:1 contrast ratio against the editor background.
